# Open External Dependencies

## C✦SMO

The remaining C✦SMO asset-import task requires the user to export and upload the approved canvas hero and product cutouts as transparent files. The current public poster and catalogue use the approved managed assets already present in the project; no live route is blocked while awaiting a replacement export.

The remaining C✦SMO keyboard item is intentionally retained as a manual verification boundary. The project has verified menu, dialog, bag-form, studio-navigation, and keyboard activation behavior, while a single uninterrupted no-assistance traversal from product-page entry through size selection and **Add to bag** remains to be performed in a future browser pass.

## Legacy KNIALL

The remaining KNIALL Shopify tasks require approved real product names, purchasable variants, prices, and media. The connected development store currently has no genuine products, so seeding, smoke-test recovery, and rendering of real-catalogue commerce data cannot be completed without those inputs.
