# zxke portfolio domain research notes

## Current portfolio signal

- URL reviewed: `https://zekecreatives.onrender.com/`
- Brand mark: **ZXKE**
- Creator framing: **“A solo studio by Zeke Cunan(an).”**
- Primary proposition: **“Make it useful.”** / **“Useful by design.”**
- Service signal: **Creative technology**

The domain should therefore prioritise the distinctive `zxke` mark over the generic `zekecreatives` phrase, while keeping an obvious route for new clients to understand that it is a creative and digital-product practice.

## Registrar and extension findings

Cloudflare Registrar states that it charges at cost for registration and renewal, supports more than 390 TLDs, and includes DNS, SSL, DNSSEC, and WHOIS redaction features.[1] Porkbun’s published pricing page currently lists a `.com` at US$11.08 for registration and renewal, `.dev` at US$8.75 for the first year and US$12.87 renewal, `.studio` at US$11.84 for the first year and US$32.44 renewal, and `.design` at US$10.81 for the first year and US$46.86 renewal.[2] The inexpensive first-year price should not decide the choice: renewal cost is the practical budget number.

## Sources

## Availability boundary

A public availability lookup for `zxke.com` did not return a completed result in the unauthenticated registrar interface. No candidate is therefore claimed available. Availability, premium status, final renewal rate, and eligibility must be confirmed in the chosen registrar’s checkout before purchase.

## Candidate checks and recommendation

The public `.com` registry endpoint returned records for `zxke.com` and `zekecreative.com`, indicating those names are already registered. It returned a not-found response for `zxkestudio.com` and `zxkecreative.com` at the time of the check. This is a promising signal, not a registration guarantee; registry and registrar results can change and premium status must still be checked.

| Priority | Candidate | Why it fits the live portfolio | Practical price direction |
|---|---|---|---|
| 1 | `zxkestudio.com` | The strongest single-name studio identity. It reads credible in client email, supports fashion/creative work and development work, and matches the site’s “solo studio” language. | Prefer `.com` for long-term clarity; published Porkbun pricing is US$11.08 for registration and renewal for a non-premium `.com`.[2] |
| 2 | `zxkecreative.com` | Closest to the current `zekecreatives` host while making the distinctive ZXKE mark the first thing a client sees. | Same sustainable `.com` route if it is non-premium.[2] |
| 3 | `madebyzxke.com` | More personal and dynamic; ideal if the portfolio leans toward authored design and development work. The public availability query timed out, so check directly. | Same `.com` pricing model if non-premium.[2] |
| 4 | `zxke.dev` | Best lower-cost alternative for a developer-forward personal portfolio; still credible but slightly narrower for art-direction-led work. | Porkbun lists US$8.75 first year and US$12.87 renewal; confirm availability.[2] |

**Recommendation:** try to register `zxkestudio.com` first. It is the cleanest, most professional name for the portfolio currently shown. If the registrar marks it premium or unavailable, take `zxkecreative.com`; if both are unavailable, use `zxke.dev` rather than a cheap promotional novelty extension with a much higher renewal.
