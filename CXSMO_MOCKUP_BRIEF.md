# C✦SMO Mockup Generation Brief

This brief converts the supplied fit-shoot references into **new, catalogue-ready product renders**. Generate one transparent PNG per object. Keep the output original and product-focused; do not include any people, visible bodies, hands, faces, text, watermarks, third-party logos, or collage layouts.

> Use this shared prompt prefix for every object:
>
> `Create a single original C✦SMO fashion product render for a fictional Y2K streetwear catalogue. Show the garment or accessory on an invisible wearer in a clean 3/4 front view, centred and fully visible, with a true transparent background (PNG alpha), no model, no skin, no mannequin head, no hands, no text, no watermark, no floor, and no cast shadow. Material photography should feel high-end, crisp, and realistic: black, bone, graphite, pearl chrome, and controlled signal-red details. Keep the silhouette readable at ecommerce-card size. Do not copy any existing commercial logo or garment exactly.`

## Object-Specific Prompt Example

> `Create the Afterimage Track Shell for the fictional C✦SMO Y2K streetwear catalogue. It is a slightly oversized black technical zip track jacket with a high collar, curved signal-red paneling across the shoulders and sides, thin chrome reflective piping, small dimensional four-point star patches, and clean covered zipper construction. Show one jacket on an invisible wearer in a 3/4 front view, sleeves naturally filled, hem and collar fully readable. True transparent PNG alpha background only. No person, no mannequin head, no hands, no text, no watermark, no floor, no shadow, no third-party logo.`

## Sheet Request Alternative

If generating a sheet is easier, use this prompt and then export each cell separately as its own alpha PNG:

> `Create an original 4 by 3 product-contact sheet for the fictional C✦SMO Y2K streetwear catalogue. Each cell has one distinct apparel or accessory item on an invisible wearer, isolated on a true transparent background: Afterimage Track Shell, Starlink Harness Sling, Arc Chain Puddle Cargo, Constellation Platform Boot, Splitline Star Rugby, Orbit Ash Hoodie, Micro Orbit Raglan Tee, Nightstar Zip Hoodie, Static Star Baby Tee, Midnight Star Sweatpant, Lunar Corset Tank, and Chrome Pleat Micro Skirt. Use consistent 3/4 front product angles, centred ecommerce framing, black/bone/graphite/chrome palette with restrained signal-red accents. No people, no faces, no hands, no text, no watermark, no background, no floor, no cast shadows, and no third-party branding.`

## Integration Notes

When each export is ready, send the individual transparent PNG files with an explicit mapping such as `afterimage-track-shell.png → Afterimage Track Shell`. The storefront can then add them as new fictional catalogue products, inventory entries, fit-edit links, and product-detail stages without claiming the fit-sheet garments are already available.
