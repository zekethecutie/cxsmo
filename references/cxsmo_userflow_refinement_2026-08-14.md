# C✦SMO User-Flow Refinement

The latest refinement changes C✦SMO from a collection of strong routes into a clearer portfolio journey. The visitor now enters through the campaign, meets a concise brand explanation, sees a continuously moving object rail, searches the fictional drop, and can create a browser-local display profile before moving into bag, checkout-preview, studio, support, and disclosure surfaces.

| Surface | Refined behavior | Boundary retained |
|---|---|---|
| Entry and discovery | The poster landing now introduces the brand path before a sideways product conveyor leads into the catalogue. The shop adds local product, colour, category, and drop search. | Search reads the twelve fictional catalogue objects in the browser only. |
| Profile continuity | Account access uses a local display handle, sign-out action, preferences, onboarding, locale, and recommendation surfaces. | It creates no credential, verified identity, purchase history, or transmitted account data. |
| Product storytelling | Shell, lip-glaze, and key-charm renders were replaced with the newly supplied approved transparent assets. Product stages now use the grid, diagonal frame, and isolated-object language of Worn in Motion. | Product descriptions and sizes remain fictional portfolio content without product-performance claims. |
| Disclosure and footer | The top presentation notice can be dismissed for a single browser session; the footer keeps the disclosure permanently available. | The portfolio, local-only, and no-payment boundary is never removed from the broader experience. |
| Guided player | The player is now a route-aware product-and-platform explainer, holds the C✦SMO build for longer, and exposes only Exit while directing the film. | Reduced-motion visitors receive a static first scene with exit access rather than automatic motion. |

The desktop and light-mode route checks cover the refreshed landing, catalogue, shell product page, and local account flow. The next manual pass should exercise object-hover sound, notice dismissal persistence, account sign-in/sign-out persistence, search terms, logo-star feedback, and the complete exit-only player sequence in a normal browser session.
