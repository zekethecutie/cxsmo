# KINFORM Portfolio Flagship Criteria

## Brand Position

**KINFORM** is a fictional contemporary apparel label for people moving through dense city days. It makes quiet, functional wardrobe pieces that hold their shape through commuting, travel, training, and off-hours. The portfolio demo is clearly fictional and is not affiliated with KNIALL or any existing retailer.

The brand takes only high-level lessons from the supplied references. The apparel system borrows technical restraint, adaptable utility, and the focus on movement found in WISDOM-style functional fashion. The storefront borrows the direct, simple product discoverability associated with mainstream fashion retail. It does not copy names, layouts, garments, or identity assets from either source.

## Design Thesis

> Soft structure for constant movement.

The site should feel like an expensive fashion editorial that happens to sell product. The first screen is atmospheric and cinematic, but the garment remains the central object and a product path is always available. The page avoids heavy dashboard cues, fake luxury language, noisy technical labels, and oversized type in every section.

| Layer | Decision |
|---|---|
| **Voice** | Specific, calm, physical, and concise. It speaks about movement, texture, and silhouette rather than hype. |
| **Typography** | Manrope for interface and product information. Barlow Condensed used only for campaign-scale statements and product numbering. |
| **Palette** | Warm porcelain, graphite, mist grey, brushed aluminium, and one faded leaf-green signal. No gold, because KINFORM must not inherit the KNIALL identity. |
| **Garments** | Four fictional unisex essentials: a structured tee, a light shell, an engineered overshirt, and a relaxed technical trouser. |
| **Product imagery** | Original transparent-background PNG cutouts, full garment visible, clean alpha, studio shadow pass, coherent light direction, and honest material appearance. |
| **Hero object** | One clothing silhouette suspended in a soft air current. A real Spline scene may replace the WebGL object only when a public embed URL exists. |
| **Interaction** | One controlled garment morph, one 3D material study, a mild parallax response, soft drawers, a focused cart, and no gratuitous animation. |
| **Commerce** | Fictional catalogue and price data will be explicitly marked as a portfolio demonstration. Real-world checkout will not be implied. |

## Page Criteria

1. The hero has a transparent garment render against a clean atmospheric field, a single short statement, and an immediate collection action.
2. The product grid is light, spacious, and product-led. Each tile supports quick colour or material preview without becoming a component gallery.
3. The detail experience centers the clothing cutout, fabric close-up, sizing, utility notes, and a controlled add-to-bag interaction.
4. The material section uses a cloth or air metaphor rather than a generic 3D orb. It must run smoothly and provide a static fallback.
5. The site has a small number of high-impact interactions. It must not look like an AI-generated collage of trends.
6. The final footer and portfolio badge make clear that KINFORM is a fictional digital commerce concept.
