# C✦SMO Account and Checkout Visual QA

## Account route

The account route now shows a clear hierarchy from local profile preferences through honest delivery, rating, and comment-ready empty states to an opt-in taste and measurement panel. The red recommendation segment deliberately separates the user-controlled onboarding flow from the editorial black account surfaces. In its unconfigured state, it correctly presents no recommendation rather than creating synthetic shopper history.

## Checkout route

The empty-bag checkout route preserves the portfolio boundary and has a clear return path to the product catalogue. The shared header shows the new **Sound off** control in addition to the appearance and bag controls. The populated multi-step sequence is implemented in the route and requires a browser-local bag line to enter, so it was not represented by the intentionally empty visual state.
