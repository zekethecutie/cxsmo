# C✦SMO Component Inspiration Notes

The next C✦SMO refinement will borrow **interaction principles**, not third-party source designs or visual identities. The public component directories reviewed offer a useful quality benchmark: clear motion hierarchy, keyboard-first navigation, visible focus treatment, and reusable gallery, carousel, and dashboard patterns.[1][2][3]

| C✦SMO surface | Original application |
|---|---|
| Transparent fashion layers | Use one quiet stage, one focal object, and CSS typography/shapes behind it rather than decorating the source image itself. |
| Lookbook and product story | Keep gallery controls visible and labelled, make each item a distinct image, and use depth only to support hierarchy. |
| Menus and comments | Use an origin-aware open/close transition, stable focus behavior, and a keyboard escape path. |
| Studio dashboard | Favor a concise quick-action rail, status chips, and expandable operational details over dense, decorative controls. |
| Theme change | Use a short pixel-grid wash on the page chrome while maintaining an immediate reduced-motion alternative. |
