# C✦SMO Route-Aware Promotional Tour Storyboard

## Tour contract

The tour begins only after the visitor presses **Play C✦SMO**. It can navigate the portfolio’s own public routes as a demonstrative sequence, but it never submits a form, mutates a bag, changes account preferences, uploads media, or impersonates a visitor. A visual cursor, selection frames, camera movement, and callouts are **cinematic overlays only**. The visitor can pause, skip chapters, mute, or exit with Escape at every point.

## Visual-motivation system

The tour has three repeatable transition grammars. **Signal wipe** uses the four-point star and a red scanline to move between brand-level pages. **Camera cut** uses a simulated depth zoom and perspective crop to move between commerce/product scenes. **Operator grid** uses a thin chrome lattice, red outline, and data-like labels to move into the studio.

The visual cursor is never clicked by browser automation. It follows a short animated path to an explanatory focus frame, pauses, and lets the scene copy explain the interface. Any actual route change is triggered only by the tour’s own visitor-started state machine.
